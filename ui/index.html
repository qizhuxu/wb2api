重新解凭证：POST /__wb2api/creds/refresh（默认 mode=file）—— 从本机 WorkBuddy 加密会话文件重新解密一份凭证，需要本机装过并登录过 WorkBuddy。 成功后模型目录缓存会被作废，页面会自动重拉。

换票续期：POST /__wb2api/creds/refresh?mode=token—— 用当前 refreshToken 找上游换一张新的 accessToken，不碰桌面端文件。 refreshToken 是会轮换的，本服务内部已做并发去重。

关闭服务（POST /__wb2api/shutdown）

请求成功后服务会在约 50ms 内 process.exit(0)。正在进行的对话会被中断。 服务不会自动重启，需要在项目目录执行 npm start。

  • 服务端只接受来自本机（127.0.0.1 / ::1）的请求；
  • 带 Origin 头的浏览器请求会被拒绝（服务端防 CSRF 的既有设计）——所以在浏览器里点这个按钮，服务端会回 403 origin not allowed，这是预期行为，请改用 npm run stop。
